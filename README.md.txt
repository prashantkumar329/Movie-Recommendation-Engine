### Project Overview

This project is a Movie Recommendation Engine built using Python and Machine Learning.

The system recommends movies similar to the movie entered by the user based on genre similarity using Content-Based Filtering.

### Technologies Used

- Python
- Pandas
- Scikit-Learn
- CountVectorizer
- Cosine Similarity

### How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the project

python movie_recommendation.py

3. Enter a movie name

Example:

Avatar

### Output Example

Movies recommended for 'Avatar':

Interstellar
Inception
Thor
Doctor Strange
The Avengers
